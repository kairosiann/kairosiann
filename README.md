### Hey there! I'm Ryan Kim 👋

Hi! My name is Ryan Kim, I'm currently a senior at Choate Rosemary Hall.    
This Github is mainly for me store and share some of the CS & Robotics projects I've done over the years.    
    
🔭 Specifically, there are two award-winning research projects I've worked, for which the code is available here. They are:     
- _Development of a conversing, temperature scanning, autonomously navigating robot to help screen for COVID-19._ [[Github Repo]](https://github.com/kairosiann/covid19_robot_project) [[Full Paper]] (https://ieeexplore.ieee.org/document/9648849)   
    - Relevant Skills: ROS1 Melodic, Ubuntu 18.04, Python, C++, Java.    
    - Notable Awards: Silver Award & \$5000 Prize @ 2021 Samsung HumanTech Paper Awards; Patent US-2023-0047316-A1 issued for [[*Autonomously navigating robot capableof conversing and scanning body temperature to help screen for Covid-19 and Operation System thereof*]] (https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/20230047316).    
    
- _JARVITS: A Novel Deep Learning IoT Traffic Control System for Efficient Real-time Detection and Control._ <!--[[Github Repo]](https://github.com/kairosiann/jarvits)--> [Full Paper]    
    - Relevant Skills: ROS1 Melodic, Ubuntu 18.04, Python, C++.    
    - Notable Awards: 2023 Regeneron (formerly Intel, Westinghouse) Science Talent Search (STS) Scholar; Best Poster at 2022 Stanford Research Conference.    
    
👯 In summer 2022, I interned in Dr. Marynel V&#0301zquez's [[Interactive Machines Group]] (https://interactive-machines.gitlab.io) at Yale University, where I worked on developing a deep learning pipeline to read patient's facial expressions from interactions with a social robot photographer in real-time to evaluate interaction performance.    
👯 In summer 2021, I interned at Omorobot, an educational and industrial robotics company, where I wokrd on automous navigation for their R1mini Pro robot. The [omo_r1](https://github.com/kairosiann/omo_r1) repository shows some of my work.
